# Resources - How to build great software with AI

Resources for the [How to build great software with AI](https://luma.com/pif0gn4b) workshop at MIT.

The workshop demo builds a simple polling app. These documents show how it was planned:

- [demo-resources.md](./demo-resources.md): the starting bullet-point requirements
- [PRD.md](./PRD.md): the product requirements document
- [data-model.md](./data-model.md): the data model for the v1 app
- [implementation-plan.md](./implementation-plan.md): the v1 plan, broken into milestones
